# Web Pixel Art Editor

PoC project to develop Web based Pixel Art Editor


## How to run
1. Clone repository
```bash
$ git clone https://github.com/atsupi/web-pixel-art-editor
$ cd web-pixel-art-editor
```

2. Install dependencies
```bash
$ pnpm install
```

3. Run application
```bash
$ pnpm run dev
```

4. Test application
```bash
$ pnpm test
```
